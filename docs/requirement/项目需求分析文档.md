## 1. 项目概述

### 1.1 项目名称
**MJFLY** - 大疆无人机移动控制应用

### 1.2 项目目标
开发一款基于 Android 平台的大疆无人机控制应用，实现通过移动端 App 对大疆无人机进行真实飞行控制，包括起飞、降落、返航、虚拟摇杆操控等功能。

### 1.3 适用场景
- 无人机飞行控制与测试
- 大疆 SDK V5 移动端开发学习
- 无人机自动化控制研究
- 飞行任务执行与监控

## 3. 功能需求

### 3.1 核心飞行控制功能

#### 3.1.1 起飞功能
- **功能描述**：控制无人机执行自动起飞
- **实现方式**：调用 DJI SDK `FlightController.startTakeoff()`
- **前置条件**：无人机已连接、SDK 已激活
- **回调处理**：成功/失败状态回调与日志记录

#### 3.1.2 降落功能
- **功能描述**：控制无人机执行自动降落
- **实现方式**：调用 DJI SDK `FlightController.startLanding()`
- **特殊处理**：降落确认机制（低电量等情况）
- **回调处理**：成功/失败状态回调

#### 3.1.3 返航功能（RTH）
- **功能描述**：控制无人机返回起飞点
- **实现方式**：调用 DJI SDK `GoHomeController.startGoHome()`
- **取消方式**：支持取消返航 `cancelGoHome()`
- **适用场景**：失控保护、低电量返航

#### 3.1.4 虚拟摇杆控制
- **功能描述**：通过屏幕虚拟摇杆实时控制无人机飞行姿态
- **控制维度**：俯仰(pitch)、横滚(roll)、偏航(yaw)、油门(throttle)
- **实现方式**：
  - `VirtualStick.enable()` 启用虚拟摇杆
  - `PositionControlData` 构建控制数据
  - `sendPositionControlData()` 发送控制指令
- **禁用方式**：`VirtualStick.disable()`

### 3.2 设备连接与管理

#### 3.2.1 SDK 初始化
- **流程**：应用启动 → SDK 初始化 → 自动注册 App
- **关键类**：`SDKManager.getInstance().init()`
- **回调**：`SDKManagerCallback` 处理各阶段状态

#### 3.2.2 设备连接监听
- **连接状态**：`ConnectionState.Connected` / `ConnectionState.Disconnected`
- **产品变更**：支持无人机产品切换通知

#### 3.2.3 SDK 激活机制
- **时机**：App 注册成功后自动激活
- **状态**：`ActivationState.Activated` / `ActivationState.ActivationFailed`
- **错误处理**：激活失败时记录错误信息

### 3.3 状态监听与管理
- **连接状态**：实时监听无人机连接/断开
- **注册状态**：监听 SDK 注册结果
- **激活状态**：监听 SDK 激活结果
- **着陆确认**：监听降落确认需求

## 7. 开发难点与解决方案

### 7.1 DJI SDK V5 嵌套解压问题

#### 问题描述
DJI SDK V5 的 AAR 包内部包含一个嵌套的 `dji.zip` 文件，其中包含了核心的 `classes.jar` 和 `.so` 库文件。Android Gradle 插件默认不会自动解压这个嵌套 ZIP，导致 `SDKManager` 等核心类无法被正确打包进 APK。

#### 症状
```
Execution failed for task ':app:linkDebugNdk'.
CMake Error: could not find native-lib.so
```

或运行时：
```
ClassNotFoundException: dji.v5.manager.SDKManager
```

#### 解决方案
使用 PowerShell 脚本 `extract_v3.ps1` 手动提取：

1. 从 Gradle 缓存找到 AAR 文件
2. 解压 AAR（本质是 ZIP）
3. 找到内部的 `dji.zip`
4. 解压 `dji.zip`，提取 `classes.jar`
5. 复制 `.so` 文件到正确目录
6. 手动复制 `classes.jar` 到 `app/libs/`

```powershell
# 核心逻辑
Expand-Archive -Path $aar -DestinationPath $tmp
# 解压嵌套的 dji.zip
Expand-Archive -Path (Join-Path $tmp "dji.zip") -DestinationPath $nestedDir
# 复制到项目
Copy-Item (Join-Path $nestedDir "classes.jar") $libsDir
```

### 7.2 SDK 激活机制

#### 问题描述
DJI SDK V5 需要通过网络进行激活验证，每次调用 `registerApp()` 都会触发激活检查。

#### 激活流程
```
应用启动 → SDKManager.init() → INITIALIZE_COMPLETE
         → registerApp() → 激活验证 → onRegisterSuccess/onRegisterFailure
```

#### 解决方案
1. 确保设备有网络连接
2. App Key 必须与包名匹配
3. 开发者账号必须完成实名认证
4. 在 `FlyApplication` 中正确实现 `SDKManagerCallback`

### 7.3 真机限制

#### 问题描述
DJI SDK V5 不支持模拟器，必须在真机上调试。

#### 解决方案
1. 使用真实 Android 设备（minSdk 24）
2. 设备必须支持 USB Host
3. 通过 USB 连接遥控器
4. 调试时使用 `adb install` 安装 APK

### 7.4 USB 连接稳定性

#### 问题描述
手机与遥控器通过 USB 连接时可能出现断连。

#### 解决方案
1. 使用高品质 USB OTG 线
2. 确保 USB 调试已授权
3. 避免在连接过程中切换飞行模式
4. 保持手机电量充足
