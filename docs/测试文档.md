## 测试前准备

### 检查清单

- [ ] Android 手机/平板，Android 7.0 以上，arm64-v8a 架构
- [ ] DJI Tello 无人机（已充电，电量 > 50%）
- [ ] 手机已开启开发者模式和 USB 调试
- [ ] 手机已连接互联网（用于 SDK 注册，连接 Tello 前需要）
- [ ] APK 已构建并安装到手机
- [ ] 空旷安全的室内/室外测试场地

### 构建安装验证

```bash
# 1. 验证 APK 是否存在
ls app\build\outputs\apk\debug\app-debug.apk

# 2. 安装 APK
adb install -r app\build\outputs\apk\debug\app-debug.apk

# 3. 验证安装成功
adb shell pm list packages | findstr com.dmj.fly
# 应输出：package:com.dmj.fly
```

### WiFi 连接准备

```
1. 开启 Tello 无人机（短按一次电源键，长按第二次直到指示灯闪烁）
2. 等待 Tello 黄色指示灯快速闪烁（表示等待连接）
3. 手机 WiFi 设置 → 连接 "TELLO-XXXXXX" 热点
4. 确认连接成功（WiFi 图标显示已连接，但无互联网）
```
