# MJFLY 测试文档

> 版本：1.0
> 更新日期：2025-05-11
> 测试环境：真机 (Android 7.0+, arm64-v8a) + DJI 无人机 + 遥控器

> 本文档提供可逐项执行的测试用例，按顺序操作，记录每项测试结果。

---

## 测试前准备

### 检查清单

- [ ] Android 手机/平板，Android 7.0 以上
- [ ] DJI 无人机（Mini 3/Mini 4 Pro/M300/M30 等支持 V5 SDK 的机型）
- [ ] DJI 遥控器（已开机并可正常连接无人机）
- [ ] USB OTG 数据线
- [ ] 手机已开启开发者模式和 USB 调试
- [ ] 有效的 DJI App Key（已配置到 `AndroidManifest.xml`）
- [ ] 手机已连接互联网（WiFi 或移动网络）
- [ ] APK 已构建并安装到手机

### 构建安装验证

```bash
# 1. 验证 APK 是否存在
ls app\build\outputs\apk\debug\app-debug.apk

# 2. 安装 APK
adb install -r app\build\outputs\apk\debug\app-debug.apk

# 3. 验证安装成功
adb shell pm list packages | findstr com.dmj.fly
# 应输出：package:com.dmj.fly
```
