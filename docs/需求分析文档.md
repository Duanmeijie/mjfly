## 1. 项目概述

### 1.1 项目定位

MJFLY 是一款基于 **DJI SDK V5 5.17.0** 开发的 Android 移动端无人机控制应用。它不是模拟器，而是**直接控制真实大疆无人机**的生产级应用。

### 1.2 目标用户

- 大疆无人机开发者/飞手
- 需要自定义移动端飞控界面的技术团队
- 学习 Android 高级开发与 SDK 集成的开发者

### 1.3 运行环境

| 项 | 要求 |
|---|---|
| 操作系统 | Android 7.0+ (API 24+) |
| CPU 架构 | arm64-v8a |
| 硬件要求 | 支持 USB Host |
| 连接方式 | USB OTG 直连遥控器 |
| 网络要求 | 互联网连接（SDK 注册需要） |

### 2.2 飞行控制需求详述

#### 2.2.1 一键起飞

- **触发条件**：飞行器已连接且 GPS 信号正常
- **实现方式**：通过反射调用 `FlightController.startTakeoff()`
- **安全约束**：起飞前确认降落区域安全
- **文件位置**：`FlightControlRepositoryImpl.kt:takeOff()`

#### 2.2.2 一键降落

- **触发条件**：飞行器处于飞行状态
- **实现方式**：通过反射调用 `FlightController.startLanding()`
- **降落确认**：部分机型需要确认降落，通过 `isLandingConfirmationNeeded` Flow 通知 UI
- **文件位置**：`FlightControlRepositoryImpl.kt:land()`

#### 2.2.3 返航 (RTH)

- **触发条件**：已记录返航点（通常起飞后自动记录）
- **实现方式**：通过反射调用 `GoHomeController.startGoHome()`
- **可取消**：支持中途取消返航
- **文件位置**：`FlightControlRepositoryImpl.kt:startRTH()`

#### 2.2.4 虚拟摇杆控制

- **控制模式**：Position Control Data 模式
- **摇杆映射**：
  - 左摇杆：油门 (Throttle) + 偏航 (Yaw)
  - 右摇杆：俯仰 (Pitch) + 横滚 (Roll)
- **发送频率**：20Hz（每 50ms 一次）
- **数据范围**：归一化 -1.0 ~ +1.0
- **实现方式**：通过反射构建 `PositionControlData` 调用 `VirtualStick.sendPositionControlData()`
- **文件位置**：`FlightControlRepositoryImpl.kt:sendVirtualStickData()`

#### 2.2.5 紧急停止

- **功能**：立即禁用虚拟摇杆 + 触发降落
- **使用场景**：突发状况时快速响应
- **文件位置**：`ControlViewModel.kt:emergencyStop()`

## 3. 架构设计

### 3.1 架构模式

采用 **MVVM (Model-View-ViewModel) + Repository** 模式：

```
View (Fragment) → ViewModel → Repository Interface → Repository Impl → DJI SDK
```

### 3.2 分层职责

| 层次 | 职责 | 技术 |
|------|------|------|
| **UI Layer** | 展示界面、用户交互、权限请求 | Fragment、ViewBinding、Navigation |
| **ViewModel Layer** | 状态管理、业务逻辑、协程调度 | ViewModel、StateFlow、Coroutine |
| **Repository Layer** | 数据抽象、SDK 调用封装、错误处理 | 接口定义、反射调用 |
| **SDK Layer** | DJI SDK 封装、连接管理、事件分发 | DjiSdkManager、Flow 状态流 |
| **DJI SDK V5** | 底层飞行控制、相机、媒体 API | SDKManager、FlightController |

### 3.3 依赖注入

使用 **Hilt 2.52** 进行依赖注入：

```kotlin
@AndroidEntryPoint          // Fragment/Activity 注入点
@HiltViewModel              // ViewModel 注入
@Inject constructor(...)    // 构造函数注入
@Singleton                  // 单例作用域
@Module @InstallIn(SingletonComponent::class)
```

### 3.4 数据流设计

所有状态通过 Kotlin **StateFlow** 驱动：

```
RepositoryImpl (MutableStateFlow)
  → Repository Interface (StateFlow/Flow)
    → ViewModel (combine/collect)
      → ViewModel UI State (StateFlow)
        → Fragment (collectIn / lifecycleScope)
          → UI 更新
```

### 3.5 SDK 集成设计

**双层初始化机制**：

1. **`attachBaseContext`**：调用 `Helper.install()` 解密 SDK 原生库
   - 反射加载 `com.cySdkyc.clx.Helper`（V5 5.10.0+）
   - 兼容 `com.secneo.sdk.Helper`（旧版本）

2. **`onCreate` 延迟初始化**：通过 `Handler.post` 延迟调用 `DjiSdkInitializer.init()`
   - 反射避免编译时直接引用 DJI 类
   - 调用 `SDKManager.getInstance().init()` 触发 SDK 注册

**反射调用设计**：`FlightControlRepositoryImpl` 中所有 DJI SDK API 调用均通过 Java 反射执行，避免编译时依赖冲突和版本兼容问题。

## 4. 技术决策

### 4.1 为什么使用反射调用 DJI SDK？

- **避免编译时依赖冲突**：DJI SDK V5 内部包含加密的 DEX 文件和复杂的 JNI 依赖
- **版本兼容**：反射调用允许 SDK 版本升级后无需修改代码（只要 API 签名不变）
- **隔离性**：SDK 类验证失败（VerifyError）不会导致整个 App 崩溃

### 4.2 为什么使用 StateFlow 而非 LiveData？

- **原生 Kotlin 支持**：与 Coroutine 生态无缝集成
- **操作符丰富**：`combine`、`map`、`filter` 等操作符简化数据流处理
- **线程安全**：默认在主线程发射和收集

### 4.3 为什么仅支持 arm64-v8a？

- **DJI SDK V5 限制**：官方仅提供 arm64-v8a 原生库
- **设备覆盖**：Android 7.0+ 的无人机控制设备均为 64 位 ARM
- **APK 体积**：减少不必要的架构支持，缩小 APK 大小

### 4.4 为什么 debug 构建不开启混淆？

- **VerifyError 风险**：ProGuard 优化会破坏 DJI SDK 的加密 DEX 结构
- **调试便利**：开发阶段需要完整堆栈信息
- **Release 构建**：仅在 release 中开启混淆，且有完整的 proguard-rules.pro 保护规则

### 4.5 Wire 版本冲突解决

DJI SDK V5 内部依赖 `wire-runtime:2.2.0`，项目不能显式声明更高版本，否则会导致 `NoSuchMethodError`。
解决方案：移除项目中的 `wire-runtime:4.9.2`，让 Gradle 解析 DJI SDK 传递的 2.2.0 版本。

## 7. 安全约束

### 7.1 飞行安全

- 降落操作需要确认对话框
- 紧急停止按钮可在异常时快速响应
- 所有飞行操作通过 `Result` 类型返回成功/失败状态

### 7.2 权限安全

启动时自动检查并申请以下权限：
- 网络：INTERNET, ACCESS_NETWORK_STATE
- 定位：ACCESS_FINE_LOCATION, ACCESS_COARSE_LOCATION
- 存储：READ/WRITE_EXTERNAL_STORAGE, MANAGE_EXTERNAL_STORAGE
- 硬件：CAMERA, RECORD_AUDIO
- 蓝牙：BLUETOOTH_CONNECT
- 其他：READ_PHONE_STATE, SYSTEM_ALERT_WINDOW, FOREGROUND_SERVICE

### 7.3 网络安全

通过 `network_security_config.xml` 允许 DJI 域名明文通信：
- `dl.djicdn.com`
- `android.dji.com`
- `dji.com`

## 8. 已知限制

| 限制项 | 说明 | 原因 |
|--------|------|------|
| 相机控制 | 当前为模拟实现 | 需接入 DJI CameraManager API |
| 遥测数据 | 当前为模拟数据 | 需通过 KeyManager 订阅真实 Key |
| 航点飞行 | 未实现 | 需要额外的 DJI Waylines SDK |
| 图传显示 | 未实现 FPV 视频流解码 | 需要接入 DJI VideoStreamManager |
| 直播功能 | 框架已搭建 | 需配置直播服务器地址 |
| 不支持模拟器 | 仅限真机运行 | DJI SDK V5 限制 |
| 仅 arm64-v8a | 不支持 x86/armeabi-v7a | DJI SDK 仅提供 arm64 原生库 |
