# MJFLY 项目使用说明书

> 版本：1.1
> 更新日期：2025-05-11

---

## 1. 产品介绍

**MJFLY** 是一款支持 WiFi 直连控制 DJI Tello 无人机的 Android 移动应用。通过手机连接 Tello 的 WiFi 热点，您可以直接在手机上控制无人机起飞、降落和使用虚拟摇杆操控，同时实时查看电池电量、温度、飞行高度等状态数据。

### 适用机型

当前主要支持：
- **DJI Tello** / Tello EDU（WiFi 直连控制）

SSID 自动检测还支持以下 WiFi 直连无人机：
- DJI Mini 3 / Mini 3 Pro / Mini 4 Pro
- DJI Mavic Air / Air 2S
- DJI Mavic 3
- DJI Avata / DJI FPV
- DJI Neo

### 手机要求

- Android 7.0 (API 24) 或以上版本
- 支持 WiFi
- CPU 架构：arm64-v8a（绝大多数现代 Android 手机）

## 2. 安装与首次使用

### 2.1 安装 APK

**方式一：USB 安装（开发/调试阶段）**

```bash
# 手机通过 USB 连接电脑后
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

**方式二：手动安装**

1. 将 `app-debug.apk` 文件传到手机
2. 在手机上点击安装

### 2.2 首次启动

1. 在手机上找到并打开 **MJFLY** 应用图标
2. 首次启动会弹出权限请求，请全部点击**允许**：
   - 位置权限（精确定位 + 粗定位）— **必须**，用于获取 WiFi SSID
   - 存储权限
   - 其他系统权限
3. 权限授予后，App 进入主界面

## 3. 设备连接

### 3.1 连接方式

```
手机 ── WiFi ── Tello 无人机热点
```

> 无需遥控器、无需 USB 线，手机 WiFi 直连即可控制。

### 3.2 连接步骤

```
第 1 步：开启 Tello 无人机
        → 短按一次电源键，再长按直到指示灯闪烁
        → 等待黄色指示灯快速闪烁（表示等待连接）

第 2 步：手机连接 Tello WiFi
        → 打开手机 WiFi 设置
        → 找到 "TELLO-XXXXXX" 热点并连接
        → 确认连接成功（无互联网是正常的）

第 3 步：打开 MJFLY App
        → App 自动检测到 Tello WiFi
        → 连接状态显示 "已连接 (WiFi: TELLO-XXXXXX)"
```

### 3.3 断开连接

```
第 1 步：确保无人机已降落
第 2 步：关闭手机 App
第 3 步：关闭 Tello（长按电源键 5 秒）
第 4 步：手机 WiFi 断开 Tello 热点
```

### 3.4 连接成功标志

App 界面显示：
- 连接状态：**已连接 (WiFi: TELLO-XXXXXX)**
- 电池电量：显示真实百分比（如 87%）
- 温度：显示芯片温度

## 4. 功能使用指南

### 4.1 界面导航

App 底部有导航标签，点击切换页面：

| 标签 | 功能 |
|------|------|
| **FPV** | 第一人称视角（视频流预览区域） |
| **控制** | 飞行控制面板（起飞、降落、摇杆等） |

---

### 4.2 飞行控制（核心功能）

#### 进入飞行控制页面

点击底部 **"控制"** 标签。

#### 起飞

1. 确保 Tello 在**平坦地面**
2. 确保周围**1 米内无人和障碍物**
3. 点击 **[起飞]** 按钮
4. Tello 自动起飞至约 1 米高度悬停

> 首次操作时，App 会自动向 Tello 发送 `command` 命令进入 SDK 模式。

#### 降落

1. 确保下方**降落区域无障碍物**
2. 点击 **[降落]** 按钮
3. Tello 自动降落至地面，桨叶停止

#### 返航

1. 点击 **[返航]** 按钮
2. 由于 Tello 无 GPS，将执行**原地降落**代替返航

#### 紧急停止

1. 点击 **[紧急停止]** 按钮
2. 虚拟摇杆立即禁用 + 触发降落
3. **仅在紧急情况下使用！**

---

### 4.3 虚拟摇杆操控

#### 什么是虚拟摇杆？

虚拟摇杆是屏幕上的两个圆形控制器，模拟真实遥控器的左右摇杆，让您通过触摸屏幕来控制无人机飞行姿态。

#### 摇杆映射

| 摇杆 | 上下方向 | 左右方向 |
|------|----------|----------|
| **左侧摇杆** | 上升 ↑ / 下降 ↓ | 逆时针旋转 ← / 顺时针旋转 → |
| **右侧摇杆** | 前进 ↑ / 后退 ↓ | 左移 ← / 右移 → |

#### 使用方法

1. 点击 **[虚拟摇杆]** 按钮启用
2. **左摇杆操作**：
   - 上下拖动：控制高度（上升/下降）
   - 左右拖动：控制偏航（原地转向）
3. **右摇杆操作**：
   - 上下拖动：前后移动（前进/后退）
   - 左右拖动：左右平移
4. 松开摇杆：自动回中，无人机保持当前悬停
5. 再次点击 **[虚拟摇杆]** 按钮禁用

#### 操控技巧

- **轻推**：微调姿态，适合精细操作
- **重推**：快速响应，快速移动
- **不要同时推到最大**：可能导致剧烈姿态变化
- **操控时注意电量**：Tello 低电量会自动降落
- **注意 WiFi 信号范围**：远离手机信号会变弱

---

### 4.4 实时状态查看

在控制页面可查看以下实时数据：

| 数据 | 来源 | 说明 |
|------|------|------|
| 连接状态 | WiFi SSID 检测 | 显示连接的无人机名称 |
| 电池电量 | Tello UDP 8890 | 真实电池百分比 |
| 温度 | Tello UDP 8890 | 芯片平均温度 |
| 飞行状态 | 高度判断 | 高度>0 为飞行中 |

## 5. 安全须知

### 飞行安全规则

1. **空旷场地**：选择开阔、无障碍的场地飞行
2. **远离人群**：远离人群、建筑物、电线杆
3. **遵守法规**：遵守当地无人机管理法规
4. **电量管理**：Tello 低电量（<10%）会自动降落
5. **WiFi 范围**：保持 Tello 在 WiFi 信号范围内（约 30 米）
6. **室内适合**：Tello 体积小，适合室内低空飞行

### 操作注意事项

1. 起飞前检查桨叶是否安装牢固
2. 不要在有风的环境飞行（Tello 抗风性弱）
3. 紧急停止按钮仅在紧急情况下使用
4. 虚拟摇杆操控时注意力集中，不要分心
5. 连接 Tello WiFi 后手机无法上网，属正常现象

## 6. 常见问题

### Q1: App 显示"未连接"怎么办？

**可能原因**：
- 手机未连接 Tello WiFi
- Tello 未开机
- 定位权限未授予（Android 8+ 需要定位权限才能获取 WiFi SSID）

**解决方法**：
1. 确认 Tello 已开机（黄灯快速闪烁）
2. 手机 WiFi 设置中连接 TELLO-XXXXXX
3. 确认已授予定位权限
4. 等待 2 秒让 App 检测到连接

### Q2: 起飞命令无响应？

**可能原因**：
- WiFi 连接不稳定
- Tello 电量过低
- UDP 命令超时

**解决方法**：
1. 确认 WiFi 连接正常（信号强度好）
2. 检查 Tello 电量 > 10%
3. 重新连接 WiFi 后再试
4. 查看日志：`adb logcat -d | findstr "TelloControl"`

### Q3: 虚拟摇杆没反应？

**可能原因**：
- 虚拟摇杆未启用
- Tello 未连接

**解决方法**：
1. 先点击"虚拟摇杆"按钮启用
2. 确认 Tello WiFi 已连接
3. 确认 Tello 在空中

### Q4: App 闪退怎么办？

**解决方法**：
1. 确保手机 Android 7.0 以上
2. 重新安装 APK
3. 查看日志：`adb logcat -d | findstr "FATAL"`

### Q5: 连接 Tello 后手机没网？

**说明**：这是正常现象。Tello WiFi 是局域网热点，不提供互联网。需要上网时断开 Tello WiFi。
