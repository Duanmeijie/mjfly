# MJFLY 项目使用说明书

> 版本：1.0
> 更新日期：2025-05-11

---

## 1. 产品介绍

**MJFLY** 是一款基于 DJI SDK V5 开发的 Android 无人机控制应用。通过手机连接 DJI 遥控器，您可以直接在手机上控制无人机起飞、降落、返航和使用虚拟摇杆操控。

### 适用机型

支持所有兼容 DJI SDK V5 5.17.0 的无人机，包括但不限于：
- DJI Mini 3 / Mini 3 Pro
- DJI Mini 4 Pro
- DJI M30 系列 (M30/M30T)
- DJI M300 RTK / M350 RTK
- DJI M3 系列 (M3E/M3T/M3M)
- DJI M4 系列
- DJI M400 RTK

### 手机要求

- Android 7.0 (API 24) 或以上版本
- 支持 USB Host 功能
- CPU 架构：arm64-v8a（绝大多数现代 Android 手机）

## 2. 安装与首次使用

### 2.1 安装 APK

**方式一：USB 安装（开发/调试阶段）**

```bash
# 手机通过 USB 连接电脑后
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

**方式二：手动安装**

1. 将 `app-debug.apk` 文件传到手机
2. 在手机上点击安装

### 2.2 首次启动

1. 在手机上找到并打开 **MJFLY** 应用图标
2. 首次启动会弹出权限请求，请全部点击**允许**：
   - 位置权限（精确定位 + 粗定位）
   - 存储权限
   - 相机/麦克风权限
   - 其他系统权限
3. 权限授予后，App 进入主界面

### 2.3 配置 DJI App Key（仅开发者需要）

> 普通用户使用的 APK 已预置 App Key，无需配置。
> 自行编译的用户需要替换 App Key：

1. 在 `app/src/main/AndroidManifest.xml` 中找到：
   ```xml
   <meta-data
       android:name="com.dji.sdk.API_KEY"
       android:value="EE45A36E38A16E49C8CF38A8" />
   ```
2. 将 `value` 替换为您在 [DJI 开发者平台](https://developer.dji.com/) 创建的 App Key

## 3. 设备连接

### 3.1 连接方式

```
手机 ── USB OTG 数据线 ── 遥控器 USB 口 ── 无人机
```

### 3.2 开机顺序（非常重要！）

> ⚠️ 必须严格按以下顺序操作，否则可能连接失败

```
第 1 步：开启遥控器
        → 等待 30 秒，确认遥控器屏幕正常显示

第 2 步：开启无人机
        → 等待 10 秒，确认桨叶未转动前状态灯正常

第 3 步：打开 MJFLY App
        → 确保 USB OTG 已连接
```

### 3.3 关机顺序

```
第 1 步：先关无人机（停止电机）
第 2 步：再关遥控器
第 3 步：最后关闭手机 App
```

### 3.4 连接成功标志

App 界面显示：
- 连接状态：**已连接**
- 电池电量：显示百分比
- SDK 注册成功（日志中可见）

## 4. 功能使用指南

### 4.1 界面导航

App 底部有 5 个导航标签，点击切换页面：

| 标签 | 功能 |
|------|------|
| **FPV** | 第一人称视角（视频流预览区域） |
| **控制** | 飞行控制面板（起飞、降落、摇杆等） |
| **遥测** | 实时飞行数据（高度、速度、姿态等） |
| **相机** | 相机控制（拍照、录像、变焦） |
| **媒体** | 媒体文件管理（浏览、下载、删除） |

---

### 4.2 飞行控制（核心功能）

#### 进入飞行控制页面

点击底部 **"控制"** 标签。

#### 起飞

1. 确保无人机在**平坦地面**
2. 确保周围**3 米内无人和障碍物**
3. 点击 **[起飞]** 按钮
4. 无人机自动起飞至约 1.2 米高度悬停

> ⚠️ 起飞前请务必确认周围环境安全！

#### 降落

1. 确保下方**降落区域无障碍物**
2. 点击 **[降落]** 按钮
3. 如弹出确认对话框，点击 **[确认]**
4. 无人机自动降落至地面

#### 返航 (RTH)

1. 点击 **[返航]** 按钮
2. 无人机会自动飞回**起飞点**并降落
3. 返航过程中如需中止，点击 **[取消返航]**

#### 紧急停止

1. 点击 **[紧急停止]** 按钮
2. 虚拟摇杆立即禁用 + 触发降落
3. **仅在紧急情况下使用！**

---

### 4.3 虚拟摇杆操控

#### 什么是虚拟摇杆？

虚拟摇杆是屏幕上的两个圆形控制器，模拟真实遥控器的左右摇杆，让您通过触摸屏幕来控制无人机飞行姿态。

#### 摇杆映射

| 摇杆 | 上下方向 | 左右方向 |
|------|----------|----------|
| **左侧摇杆** | 上升 ↑ / 下降 ↓ | 逆时针旋转 ← / 顺时针旋转 → |
| **右侧摇杆** | 后退 ↓ / 前进 ↑ | 左移 ← / 右移 → |

#### 使用方法

1. 点击 **[虚拟摇杆]** 按钮启用
2. **左摇杆操作**：
   - 上下拖动：控制高度（上升/下降）
   - 左右拖动：控制偏航（原地转向）
3. **右摇杆操作**：
   - 上下拖动：前后移动（前进/后退）
   - 左右拖动：左右平移
4. 松开摇杆：自动回中，无人机保持当前悬停
5. 再次点击 **[虚拟摇杆]** 按钮禁用

#### 操控技巧

- **轻推**：微调姿态，适合精细操作
- **重推**：快速响应，快速移动
- **不要同时推到最大**：可能导致剧烈姿态变化
- **操控时注意电量**：低电量时尽快降落

### 4.4 相机控制

#### 进入相机页面

点击底部 **"相机"** 标签。

#### 拍照

1. 选择 **PHOTO** 模式
2. 点击中间大圆形 **[拍照]** 按钮

#### 录像

1. 选择 **VIDEO** 模式
2. 点击 **[录像]** 按钮开始
3. 再次点击停止录像
4. 录制时红色指示灯亮起

#### 变焦

拖动底部的 **变焦滑块**，从 1x 调整到 10x。

---

### 4.5 遥测数据查看

#### 进入遥测页面

点击底部 **"遥测"** 标签。

#### 可查看的数据

**飞行器状态区**：
- 连接状态
- 飞行模式
- 电池电量
- GPS 信号
- 电机状态
- 飞行时间

**飞行遥测区**：
- 经纬度坐标
- 相对高度
- 超声波高度
- 起飞高度
- 姿态角（俯仰/横滚/偏航）
- 速度（X/Y/Z 轴）

---

### 4.6 媒体管理

#### 进入媒体页面

点击底部 **"媒体"** 标签。

#### 浏览文件

点击 **[刷新]** 按钮加载无人机上的媒体文件列表。

#### 下载文件

点击文件旁边的 **[下载]** 按钮，文件将下载到手机存储。

#### 删除文件

点击 **[删除]** 按钮删除不需要的媒体文件。

## 5. 安全须知

### ⚠️ 飞行安全规则

1. **空旷场地**：选择开阔、无障碍的场地飞行
2. **远离人群**：远离人群、建筑物、电线杆
3. **遵守法规**：遵守当地无人机管理法规（如高度限制、禁飞区等）
4. **电量管理**：确保电量充足再起飞，低电量时及时降落
5. **天气条件**：避免大风、雨雪天气飞行
6. **视距内飞行**：保持无人机在视线范围内

### ⚠️ 操作注意事项

1. 起飞前检查桨叶是否安装牢固
2. GPS 信号弱时不要起飞
3. 不要在禁飞区（机场附近、军事区域等）飞行
4. 紧急停止按钮仅在紧急情况下使用
5. 虚拟摇杆操控时注意力集中，不要分心

## 6. 常见问题

### Q1: App 闪退怎么办？

**可能原因**：
- SDK 初始化失败
- 网络问题导致注册失败

**解决方法**：
1. 确保手机网络连接正常
2. 重新启动 App
3. 查看日志：`adb logcat -d | findstr "FATAL"`

### Q2: 显示"未连接飞行器"？

**可能原因**：
- 遥控器未通过 USB 连接手机
- 开机顺序不正确
- USB OTG 线故障

**解决方法**：
1. 确认 USB OTG 线正常连接
2. 严格按开机顺序操作（先遥控器 → 再无人机 → 最后 App）
3. 更换 OTG 线测试

### Q3: SDK 注册失败？

**可能原因**：
- App Key 不正确或与包名不匹配
- 网络连接失败

**解决方法**：
1. 确认 DJI App Key 正确
2. 确认包名为 `com.dmj.fly`
3. 确保网络通畅
4. 确认 DJI 开发者账号已完成实名认证

### Q4: 虚拟摇杆没反应？

**可能原因**：
- 虚拟摇杆未启用
- 飞行器未连接

**解决方法**：
1. 先点击"虚拟摇杆"按钮启用
2. 确认飞行器已连接
3. 确认 GPS 信号正常

### Q5: 电池显示不准确？

**说明**：当前电池数据为模拟数据。接入真实 DJI SDK 的 KeyManager 后，将显示真实电池信息。

### Q6: 相机拍照/录像没效果？

**说明**：当前相机功能为模拟实现。接入真实 DJI SDK CameraManager 后，可控制真实相机。
